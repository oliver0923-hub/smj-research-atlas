# v3 驗收與不可避免的限制

實際數值以網站 data/coverage_report.json 及最近成功工作為準。本次基線 3,949 DOI，Taxonomy v2 保留，不重置既有歷史。GitHub 權限已確認 admin、push、maintain。

已實作自動證據軸、無人工發布門檻、摘要特徵補充、合法正文嘗試、PDF/HTML 解析、逐篇衡量 span 對齊、可分享 URL 的模糊搜尋、來源頁、變數 CSV 與比較表、年度分母／主題共現／Theory × Topic、來源品質與資料分支發布。

未完成的研究級覆蓋：

- 初始目標為 30–50 篇可用 empirical 正文；本次實際只有 10 篇可解析正文（101 篇獨立論文已嘗試），其中 7 篇得到一筆明確衡量。不能把 101 次目標論文或 OA 位置數當成成功全文數。已實作可擴張的週更擷取，但不宣稱已達 30–50 篇成功正文。
- 每篇最多一筆 named measure，並非完整 IV/DV/control 列表；角色、樣本期間、lag、估計法及係數多數未知。原文符號公式目前無可驗證紀錄，公式數為零。
- 出版社目錄 403，完整 SMJ 母體與漏收比例未知；書目文章類型也尚未全面核實。來源中缺少作者等欄位不捏造補齊。
- 詞彙向量不是深層 semantic embedding；付費模型 adapter 預設關閉。沒有 held-out 人工 gold set，因此分數不是校準機率，也不報告 precision／recall。
- 新興雙詞組候選有文件數、分母與期間，但尚無語意新穎性驗證；保留 provisional，不自動提升 taxonomy 或研究缺口。
- 相近構念不做未經證據的語意合併；方法、資料來源、sample、finding 表在缺乏來源時保留空或未知。

這些是資料存取或抽取能力的實際邊界，不是要求擁有者參與逐篇人工審核的待辦。


正式站驗收：GitHub Pages 已部署；五篇代表論文頁均顯示 E3 衡量、PDF 頁碼與未知欄位。拼字容錯、多 Domain 篩選、可分享 URL 還原、變數 CSV 下載、分析分母切換及 390px 手機排版已實際操作通過。自動資料發布於 GitHub 成功完成書目同步、品質 gate、測試、建置、資料分支寫入與 Pages 部署。驗證的是程式及來源一致性，不宣稱已達專家標註準確率。
